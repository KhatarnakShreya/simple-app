# Neon Snake

A small browser-based Snake game built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Controls

- Use the arrow keys to move.
- Press `Space` or the pause button to pause and resume.
- On touch devices, swipe on the board or use the directional pad.
- Select **Play again** after a run ends to restart.

## Gameplay

Eat the coral light to grow and earn 10 points. Avoid the board edges and your own trail. Your best score is saved in the browser with `localStorage`.

## Files

- `index.html` contains the game structure.
- `style.css` contains the responsive neon arcade styling.
- `script.js` contains the canvas game loop, controls, scoring, and game states.
